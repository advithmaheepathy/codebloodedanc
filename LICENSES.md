simulation tool that contributes to the evaluation set or the runtime path is listed here.

### Notes

- **dataset_plain (supplied by the project team)** (NOT VERIFIED - supplied to this repository, provenance not confirmed here): This is the corpus every number in the report is measured on. It was provided rather than assembled here, so its licence could not be verified from inside this project and must be confirmed before any redistribution or commercial use. What the filenames indicate: the speech is LibriSpeech (CC BY 4.0) - the speech_source column holds LibriSpeech flac identifiers such as 3081-166546-0008.flac. The siren, train, airplane, helicopter and engine noise uses ESC-50 clip naming (CC BY-NC 3.0), e.g. 5-133989-B-42.wav. The gunshot noise (4385 of 5000 examples) is named by weapon and geometry, e.g. ak-47_002_ak_100m_back_0901.wav, which points at a dedicated gunshot corpus with range and bearing annotations; its terms are unknown here. Treat the whole set as non-commercial until each component is confirmed.
- **ESC-50: Dataset for Environmental Sound Classification** (CC BY-NC 3.0): Non-commercial licence. Acceptable for this research prototype; would have to be replaced before any commercial or fielded use. 5 s clips at 44.1 kHz, resampled to 48 kHz.
- **LibriSpeech ASR corpus (dev-clean subset)** (CC BY 4.0): 16 kHz source, upsampled to 48 kHz. The absent high band does not affect the reported metrics (PESQ-WB is computed at 16 kHz, STOI at 10 kHz) but it does mean this evaluation set does not exercise the model's fullband capability. Read from LibriVox public-domain audiobooks.
- **Procedural noise generated by this repository** (MIT (this repository)): Parametric engine/rotor/wind/siren/drone/gunshot models. Used so the pipeline is always runnable offline. Clearly labelled in manifests as source='synthetic'.
- **pyroomacoustics image-source room simulation** (MIT): RIRs are simulated, not measured. Room dimensions and RT60 are logged per mixture.
- **DeepFilterNet3 pretrained model** (MIT / Apache-2.0 (dual)): Weights downloaded by the deepfilternet package and cached locally.

## Considered and not used

- **AudioSet**: Provides labels plus YouTube identifiers rather than audio. Downloading the audio is not clearly permitted, so it is not used.
- **NOISEX-92 / NOISEUS**: Redistribution terms are unclear. Not downloaded. ESC-50 covers the same classes (machine gun, helicopter, engine, factory-like machinery) with an explicit licence.
- **UrbanSound8K, FSD50K, MUSAN, DEMAND**: Suitable and licensed, but not needed: the evaluation set is minutes long and ESC-50 already covers every category. Registered here so the choice is a recorded decision, not an omission.

## Consequence

**The runtime path is clean.** DeepFilterNet3 is MIT/Apache-2.0, and everything this
repository adds is MIT. Nothing in the shipped pipeline carries a restriction.

**The evaluation audio is not.** `dataset_plain` was supplied to this project and its
provenance was not verified here; the filenames point at LibriSpeech (CC BY 4.0) for speech
and ESC-50 (CC BY-NC 3.0) for most of the non-gunshot noise, while the gunshot material's
terms are unknown. ESC-50 alone makes the set **non-commercial**. Before publishing results
or redistributing anything:

1. confirm the source and licence of the gunshot corpus (4385 of 5000 examples),
2. confirm the ESC-50 attribution requirement is met,
3. keep the audio out of any public release of this repository - `.gitignore` already
   excludes `dataset_plain/` and `data/`.

Retraining or redistribution on a permissive footing would mean swapping the noise for
FSD50K or MUSAN clips, both of which are licensed for that use.
